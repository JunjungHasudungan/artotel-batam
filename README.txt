ARTOTEL BATAM — BEST EMPLOYEE VOTING (DEMO LOKAL)

CARA PAKAI
1. Ekstrak ZIP.
2. Buka index.html di browser untuk halaman voting.
3. Buka admin.html untuk dashboard hasil. Password awal: 12345.
4. Edit app.js dan admin.js dengan nama kandidat, departemen, dan file foto yang sesuai.
5. Simpan foto kandidat di folder assets, misalnya assets/angga.jpg, lalu ubah path foto di app.js dan admin.js.
6. Untuk GitHub Pages, upload seluruh isi folder dengan struktur tetap sama.

PENTING
Versi ini memakai localStorage. Suara hanya tersimpan di browser/perangkat yang dipakai dan tidak tersinkron antar-HP/komputer. Password admin di file JavaScript bukan keamanan sungguhan. Untuk voting lintas perangkat dengan hasil admin terpusat, dibutuhkan backend/database online dan autentikasi admin.
